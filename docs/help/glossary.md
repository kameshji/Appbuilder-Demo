# Glossary

| Word | What it means |
| --- | --- |
| **Administrator** | The person in your company who looks after Appbuilder: adds people, gives access, solves problems. |
| **App** | A set of screens made by your company for one job. |
| **Approval** | A request that waits for a person to say yes or no. Approval screens are still being built. |
| **Authenticator app** | An app on your phone (for example Google or Microsoft Authenticator) that shows a 6-digit code that changes every 30 seconds. |
| **Avatar** | The circle with your initials at the top right. |
| **Bell** | The icon in the top bar that shows your notifications. |
| **Column** | One kind of information in a table, for example "Customer" or "Quantity". |
| **Comment** | A written note on a record. |
| **CSV file** | A simple table file that opens in Excel. |
| **Digest** | One email that collects several notifications, sent hourly or daily. |
| **Environment** | A separate copy of the system, for example "Production" (daily work) and "Test". You normally work in Production. |
| **Field** | A box in a form where you type or choose something. |
| **Follow** | Ask to be notified about new comments on a record. |
| **Form** | A screen for adding or changing a record. |
| **List / table** | A screen that shows many records in rows. |
| **Mention** | Writing @ and a name in a comment, so that person is notified. |
| **My apps** | The page that lists the apps you may use. |
| **Notification** | A message about something that needs you, under the bell or by email. |
| **Owner** | The person who created a record. Some roles see only the records they own. |
| **Password manager** | A program that stores your passwords safely so you need to remember only one. |
| **Quiet hours / Do not disturb** | Hours when you do not want pop-ups or emails. |
| **Read-only** | You can look but not change. |
| **Record** | One row in a table: one order, one person, one machine log. |
| **Recovery codes** | Ten one-time codes you save when you set up two-step verification, to sign in if you lose your phone. |
| **Report (scheduled)** | An email with a table sent on a timetable. |
| **Role** | A set of permissions your administrator gives you. It decides which apps you open and which records and columns you see. |
| **Row** | One record in a list. |
| **Session** | One signed-in browser or device. |
| **Tab** | An open app shown under the top bar, like a browser tab. |
| **Task** | A to-do about a record or for you, with a due date. |
| **Timeline** | The list on a record of its comments, tasks, files and changes. |
| **Two-step verification** | Signing in with your password **and** a code from your phone. |
| **User mode** | The part of Appbuilder where people use apps (as opposed to Dev mode, where apps are built). |
| **Validation message** | The red text under a field that says what is wrong. |
