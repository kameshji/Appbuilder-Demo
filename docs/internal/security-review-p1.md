# Security review of Phase 1 (package E)

Internal review of everything Phase 1 added (packages A to D: the flow runtime and designer, connector actions, the HTTP
and Email connectors, webhooks, notification delivery, scheduled reports, approvals, the admin recovery CLI, request
references), done at the phase close on 19 Nov 2026 by reading the code and then attacking it with tests. It is a review
by the people who built it (the recycle bin, finished the same day, included), not an outside audit (that comes before the pilot goes beyond one company, master plan
section 5). The format follows [the Phase 0 review](security-review-p0.md). Severity is for this product's threat model
([security model](../admin/security-model.md#threat-model)): one PC, trusted administrators and makers, untrusted ordinary
users, web pages and callers of webhooks.

Tests named here: `server/core/security-p1.test.ts` (S-U), `server/core/security-p1.integration.test.ts` (S-I), plus the
existing suites they extend (`actions/actions.test.ts`, `actions/actions.integration.test.ts`, `flows/*.test.ts`,
`approvals/*.test.ts`, `identity/admin-cli.integration.test.ts`, `request-id.test.ts`).

## Residual risks (carried into the security model page)

- **Regular expressions**: the server refuses nested repeats, a heuristic; other super-linear patterns (overlapping
  alternatives such as `(a|aa)*$`) are not caught, and one regular-expression call cannot be interrupted by the
  evaluation budget.
- **Evaluation budget** is checked between evaluation steps; a single native call (a sort of a large table) runs to its end.
- **Webhooks**: a slow request body holds a connection until the server's request timeout (10 minutes); behind Caddy the
  proxy's timeouts apply. Whether an environment id exists can be told from the answer time (never the token).
- **Makers are trusted**: any maker can read the saved definition of any flow and change any approval policy (changes
  apply to new requests only); the HTTP connector's allow-list is the boundary for what a flow can reach.
- **Loop protection** stops chains at 8 levels: a ping-pong between two flows still writes up to 8 rows per seed row.
- **Recycle bin**: deleted rows remain in the table, the database and backups until their batch is purged (30 days by
  default); "deleted" is not "erased" for privacy requests: delete for good (administrators) for that.
- **OAuth token addresses and the SMTP relay** may be on private networks (like the relay itself); only administrators set them.
- Carried from Phase 0: DNS rebinding for database connections, unsigned backup archives, download tickets in URLs, no
  outside review.
