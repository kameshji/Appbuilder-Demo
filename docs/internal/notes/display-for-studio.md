# Display controls: what the runtime must do (from the Display agent's hand-back)

Controls live in src/controls/display/* plus upgraded Container.tsx, Screen.tsx, Gallery.tsx.

1. Layout boxes (Container, Screen, Row, Column, Grid, Card, ScrollArea, Dialog, Sheet, TopBar): pass `children` straight through. Exactly one children box carries `data-layout="manual|row|column|grid"`; it is `position: relative; box-sizing: border-box`, and in row/column/grid mode it is the flex/grid container (gap, padding, justify, align, wrap, grid-template-columns). Padding applies in every mode, so children in a Manual box are offset by the padding box. The children box is NOT always the control's root: for Card, Dialog and Sheet it is the body below a header. Find it with `[data-layout]` and size/anchor children against that box, not the control wrapper.
   Shared layout props: LayoutMode (Layout.Manual default; Row/Column/Grid presets on Row/Column/Grid/ScrollArea), Gap, Padding (=0), Justify, AlignItems, Wrap, Columns, Scroll.
2. Dialog and Sheet (isContainer + isOverlay): design mode = in-place card filling the wrapper with a small tag; children editable in the body. Run mode = render nothing unless evaluated `Open` is true; when open they render `position: fixed; inset: 0; z-index: 200` with a backdrop. Panel size comes from the control's own evaluated Width/Height (Dialog centred; Sheet Left/Right = Width wide, full height; Top/Bottom = Height tall, full width). Close button, backdrop click (CloseOnBackdrop) and Escape call fire('OnClose'); the maker's OnClose sets the Open variable false. Give the app frame `transform: translateZ(0)` or `contain: layout` so the fixed backdrop clips to the app frame; the overlay's own wrapper must not be overflow hidden and in run mode must not constrain it to its design rect.
3. Gallery (isTemplate): rows are `[data-gallery-row]` boxes. Vertical: 100% × TemplateHeight. Horizontal: TemplateWidth × TemplateHeight. Grid: 1fr of Columns × TemplateHeight. Position template children against the ACTUAL measured row box (anchors apply). Gallery `Layout` is a text enum "Vertical" | "Horizontal" | "Grid" (not the Fx Layout enum). New outputs AllItems, VisibleCount. Design mode still shows one blank template row when Items is empty.
4. setOutput must skip writes when the value is unchanged (controls write selection outputs from effects).
5. Reset(Control) clears outputs; controls re-initialise from Default.
6. Events to evaluate: OnSelect (Tabs, TagList, Breadcrumb, NavMenu, List, Steps, TopBar, Accordion, Calendar, DataTable, Chart, Icon), OnClose (Dialog, Sheet), OnDismiss (Alert), OnAction (EmptyState), OnChange (Pagination), OnEnd (Video, Audio).
7. NavMenu does not navigate by itself: output `SelectedScreen` carries the row's Screen text; makers write Navigate(...) in OnSelect.
8. DataTable with blank Columns hides `__*` fields and `id`, but still shows system columns (createdOn, owner...). Generated apps should set Columns. Column entries are `field` or `field:Header`.
9. Insert categories: Layout, Display, Data, Navigation, Feedback, Media, Charts (+ Input from the inputs set).
